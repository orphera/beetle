# 단축키 정리 기획

2026-11-02. `beetle-app`에서 키보드 단축키를 화면별로 정리하고, 겹치거나 앞뒤가 맞지 않는 곳과 정리 방향을 적는다. 레인 키(건반 배치)는 키 설정 화면에서 바꾸는 것이라 여기서 다루지 않는다. 패드는 [controllers.md](../specs/controllers.md)를 본다.

코드 위치: 전역 키는 `crates/beetle-app/src/main.rs`(키 입력 처리 앞부분), 화면별 키는 `crates/beetle-app/src/handlers/`, 곡 메뉴는 `song_menu.rs`.

## 1. 지금 있는 단축키

### 1.1 전역 (모든 화면)

| 키 | 동작 | 비고 |
|---|---|---|
| Alt+Enter | 전체 화면 / 창 모드 | |

2026-11-02(H1)에 전역 F6~F9(게이지, 레인 옵션, 판정 오프셋 ±2 ms)를 없앴다. 이 값들은 플레이 옵션 패널과 설정에서 바꾼다.

### 1.2 타이틀

| 키 | 동작 |
|---|---|
| ↑↓ / K J | 항목 이동 |
| Enter | 고르기 |
| ESC | 종료 확인 창 (확인 창에서 Enter·Y 종료, ESC·N 취소) |

### 1.3 선곡

| 키 | 동작 |
|---|---|
| ↑↓ / K J | 곡 이동 |
| → / ← | 묶음 행이면 채보 바꾸기, 아니면 폴더 들어가기 / 나오기 |
| PageUp / PageDown, Home / End | 한 화면씩, 처음 / 끝 |
| Enter / Space | 폴더 열기, 곡 시작 |
| Backspace | 위 폴더로 |
| ESC | 위 폴더로, 루트에서는 타이틀로 |
| F1 / F3 | 같은 깊이의 이전 / 다음 폴더 |
| F2 | 정렬 바꾸기 |
| F4 | 설정 |
| F5 | 곡 목록 다시 읽기 |
| F6 | 콘텐츠 출처 탭 (서재 / CS 디스크) |
| F10 | 필터 줄로 이동 (←→ 항목, Enter 실행, ↑↓ 레벨 값, ESC·F10 나가기) |
| F12 / C | 키 설정 |
| Tab / O | 플레이 옵션 패널 |
| A | 자동 플레이 켜기 / 끄기 |
| R | 저장된 리플레이 재생 |
| M | 곡 메뉴 (폴더 열기·삭제·버전·숨기기) |
| / | 검색 (ESC 닫기, Enter 확정) |
| ? / H | 도움말 |

정렬 메뉴와 곡 메뉴 안에서는 ↑↓·K J로 움직이고, Enter·Space로 고르고, ESC로 닫는다(곡 메뉴는 M으로도 닫힌다).

**플레이 옵션 패널**: ↑↓ / K J로 줄을 옮기고, ←→로 값을 바꾼다. Space는 값을 다음으로 넘기고, Enter는 패널을 닫고 고른 곡을 시작한다. Tab·ESC는 패널을 닫는다 (H3).

### 1.4 로딩

| 키 | 동작 |
|---|---|
| ESC | 취소 |

### 1.5 플레이

| 키 | 동작 |
|---|---|
| F3 / PageUp / 1 | 노트 속도 빠르게 (녹색 숫자 작게) |
| F4 / PageDown / 2 | 노트 속도 느리게 |
| F10 / F11 | 레인 커버 +5% / -5% (0~80%) |
| ESC | 일시정지 |

**일시정지 메뉴**: ↑↓ / K J로 고르고, Enter·Space로 실행한다. ESC는 다시 시작하고, R은 처음부터 다시 한다.

**끝 배너**: Enter나 ESC를 누르면 바로 결과 화면으로 간다.

### 1.6 결과

| 키 | 동작 |
|---|---|
| Enter / Space / ESC | 선곡으로 |
| R | 다시 하기 |
| Tab | 옵션 패널 (Enter: 이 옵션으로 다시 하기, ←→·Space: 값 바꾸기, Tab·ESC: 닫기) |
| P | 스크린샷 |

### 1.7 설정

| 키 | 동작 |
|---|---|
| ↑↓ / K J | 줄 이동 |
| ←→ / H L | 값 바꾸기 |
| Enter / Space | 줄 실행 (하위 화면, 버튼) |
| ESC | 나가기 |

**판정 오프셋 측정 화면**: ESC로 취소하고, R로 다시 잰다. 측정이 끝나면 Enter로 적용한다.

### 1.8 키 설정

| 키 | 동작 |
|---|---|
| ←→ / H L | 레인 고르기 |
| ↑↓ / K J | 키 모드 바꾸기 |
| Enter / Space | 고른 레인 키 다시 정하기 |
| A | 키 하나 더 추가 |
| Backspace | 고른 레인 키 지우기 |
| Delete | 이 모드 배치 초기화 |
| F1 | 프리셋 바꾸기 |
| F2 | 스크래치 쪽 바꾸기 (해당 모드만) |
| F3 | 배치 모양 바꾸기 (6키 일자 / 트리거 등, 해당 모드만) |
| ESC | 나가기 |

## 3. 정리 방향 (제안)

1. **전역 키는 Alt+Enter만 남긴다.** F6~F9 전역 처리를 없앤다. 게이지, 레인 옵션, 판정 오프셋은 선곡과 결과의 옵션 패널, 그리고 설정에서 바꾼다. 꼭 키로 남겨야 한다면 선곡 화면의 키로 옮기고, 바뀌었을 때 토스트로 알린다.
2. **플레이 중 키는 화면에 보이는 것만 둔다.** 속도(F3/F4, 1/2, PageUp/PageDown), 커버(F10/F11), ESC만 둔다. 판정 오프셋은 플레이 중에 바꾸지 않는다.
3. **옵션 패널을 하나로 맞춘다.** ←→로 값을 바꾸고, Space는 값을 넘기고, Tab·ESC는 닫는다. Enter는 "이 옵션으로 시작"(선곡) / "다시 하기"(결과)로 같은 뜻으로 쓴다.
4. **확인 키를 맞춘다.** Enter와 숫자 패드 Enter를 모든 화면에서 같게 받는다. `input.rs` 같은 곳에 `is_confirm(code)` 하나를 두고 핸들러가 함께 쓴다.
5. **방향 키 대체를 정한다.** 위아래는 K J를 모든 목록에서 받는다(지금도 거의 그렇다). 좌우 H L은 목록·값 바꾸기에서만 받고, 선곡에서는 H가 도움말이라 받지 않는다. 이 규칙을 이 문서에 적어 둔다.
6. **도움말 표를 이 문서와 맞춘다.** 선곡 도움말(? / H)과 플레이 안내 줄(`strings.rs`)이 위 표와 같은지 보고, 단축키를 바꿀 때 함께 고친다.
