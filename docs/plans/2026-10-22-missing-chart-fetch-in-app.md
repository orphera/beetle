# 게임 안에서 없는 곡 받기

날짜: 2026-10-22 · 대상: `crates/beetle-app`, `crates/bms-package-manager`, `crates/bpm-gui`

## 문제

난이도표에서 아직 없는 곡을 찾아 받는 기능은 `bpm table fetch`와 `bpm-gui` 난이도표 탭에만 있다
([2026-10-09-missing-chart-download-design.md](2026-10-09-missing-chart-download-design.md) §7).
게임에서는 가진 곡만 보이고, 없는 곡을 받으려면 고급 도구를 열어야 한다.

## 목표

- 게임의 난이도표 폴더에서 없는 곡을 보고, 곡 메뉴에서 한 곡씩 받는다.
- 받기 규칙은 기존 설계를 그대로 쓴다: 사용자가 고른 곡만, 받기 전에 링크를 보여 주고 확인,
  호스트를 추정하지 않음, 받은 뒤 해시가 표 항목과 같을 때만 보관, 자동화 방지 화면은 우회하지 않음, 일괄 받기 없음.
- 받는 로직은 한 곳에 둔다. 게임과 `bpm`·`bpm-gui`가 같은 함수를 부른다(M11 S1과 같은 방식).

## 결정 (2026-10-22 확정)

1. **없는 곡은 필터로 켠다.** 기본은 지금처럼 가진 곡만 보인다. 필터 줄의 "없는 곡 포함"을 켜면 난이도표 폴더에
   흐린 행으로 섞여 보인다.
2. **게임 실행 파일 크기 증가를 받아들인다.** `ureq`(rustls)를 게임에 링크하고 증가량을 측정해 기록한다(N5).
3. **받은 곡은 `songs/<표>/<번호>`에 둔다.** 지금 `bpm table fetch`가 쓰는 규칙 그대로다. `.bmsp`로 묶지 않는다
   (차분과 본체를 합치는 흐름이 단순해진다).

## 단계

- **N1** 받기 진입점을 라이브러리로 모으고 보고 구조체를 돌려준다.
- **N2** 필터 "없는 곡 포함"과 흐린 행("없음" / "본체 필요").
- **N3** 없는 곡의 곡 메뉴: 받기(확인 → 워커 → 진행 토스트 → 해시 확인 → 다시 읽기 → 커서), 본체 페이지 열기.
- **N4** "본체 필요" 곡에 본체 폴더를 골라 차분을 넣기.
- **N5** 크기 측정과 기록.

## 하지 않는 것

- 표 전체 일괄 받기, 호스트 추정, 자동화 방지 화면 우회.
- rar·7z 링크 받기(지금처럼 브라우저로 열기만).
