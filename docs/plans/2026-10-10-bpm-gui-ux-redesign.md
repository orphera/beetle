# bpm-gui UX 개편 — BMS를 모르는 사람도 쓰는 곡 관리자

날짜: 2026-10-10 · 대상: `crates/bpm-gui`

## 목표

BMS를 처음 보는 사람이 설명서 없이 곡을 넣고, 받고, 지울 수 있게 한다.
기존 화면은 키보드 전용이었고(마우스는 탭과 목록만 됨), 경로를 직접 타이핑해야 했으며,
`state`, `delta`, `companion BGA`, `Turbo Dual Atlas`, `diet` 같은 내부 용어가 그대로 보였다.
Esc 한 번에 창이 닫히고, `U`/`Delete`는 확인 없이 곧바로 삭제했다.

## 결정

- **한국어 UI**, 내부 용어는 쉬운 말로: 탭 `내 곡 / 곡 받기 / 난이도표`, state → "버전",
  companion BGA → "배경 영상(별도)", delta → "업데이트 파일", body/diff → "곡 파일(본체)/채보(차분)".
- **마우스 우선**: 모든 동작이 버튼. 그리는 쪽이 클릭 영역(`widgets::Hit`)을 기록하고 클릭은
  그 목록에서 찾는다 — 레이아웃 계산을 이벤트 처리기에 중복하지 않는다. 호버 강조, 휠 스크롤
  (`ListView`: 선택과 스크롤 위치를 분리), 키보드 단축키는 그대로 유지.
- **경로 입력 대신 파일 선택 창**: `file_dialog.rs`가 Windows `IFileOpenDialog`를 COM vtable로
  직접 호출한다(새 크레이트 없음, `clipboard.rs`와 같은 방식). 별도 스레드에서 열어 메인 창은
  계속 그려진다.
- **"곡 추가" 하나로 통일**: 폴더(여러 곡이 든 상위 폴더 포함), 압축 파일(.zip/.rar/.7z — 풀어서
  가져옴), `.bmsp`, `.bmdp`를 경로 종류로 판별한다(`tasks::add_path`). 창에 끌어다 놓기도 같은 경로.
  끌어다 놓는 동안 안내 오버레이를 보여 준다.
- **빈 화면이 할 일을 알려 준다**: 곡이 없을 때, 온라인 목록이 없을 때, 난이도표가 없을 때,
  내 곡을 아직 확인하지 않았을 때 각각 설명과 버튼 하나.
- **위험한 동작은 확인**: 곡 삭제(전체/버전), 배경 영상 지우기, 채보 받기. Esc는 더 이상 창을 닫지 않는다.
- **난이도표 GUI 추가**: 주소를 넣으면 `fetch_table` + `TableStore::install` (이전에는 CLI 전용).
  선택한 항목은 "1. 곡 파일 받으러 가기 → 2. 받은 곡 파일 추가 → 3. 채보 받기" 순서 버튼으로 안내.
- **고급 기능은 한 단계 안으로**: 패키지 만들기, 업데이트 파일 적용/만들기는 "고급 도구" 대화상자.
  패키지 옵션은 단축키 토글 대신 설명이 붙은 선택 버튼. 업데이트 파일 만들기는 경로 두 칸
  (공백이 든 경로가 깨지던 `<base> <target>` 한 칸 입력을 대체).
- **진행 표시**: 상단 카드에 제목·단계·진행 막대(전체 크기를 모르면 움직이는 막대)·취소 버튼.
  상태 표시줄은 성공(초록)/오류(빨강)/정보로 구분.

## 구조

| 파일 | 역할 |
|---|---|
| `widgets.rs` | 테마 색, 둥근 상자, 실제 px 크기 텍스트, 버튼/체크박스/입력칸, `Hit`, `ListView` |
| `ui.rs` | `Frame` 하나로 한 프레임을 그림: 헤더, 세 페이지, 대화상자, 작업 카드, 상태줄 |
| `dialogs.rs` | 대화상자 종류와 입력칸, `DialogView` 생성 |
| `tasks.rs` | 백그라운드 작업(INV-5): 추가/설치/패키지/업데이트/온라인 설치/목록 동기화 |
| `file_dialog.rs` | Windows 파일·폴더 선택 창 |
| `tables_tab.rs` | 난이도표 탭 상태만 (그리기는 `ui.rs`) |
| `snapshot.rs` | 화면을 BMP로 렌더링하는 테스트 (`cargo test -p bpm-gui snapshot -- --ignored`) |

`main.rs`에서 같은 코드가 끌어다 놓기와 대화상자에 두 벌씩 있던 가져오기/설치/패키지 처리를
`tasks.rs` 하나로 합쳤다.

## 폰트

내장 Latin 폰트는 Basic Latin만 있어 `·`(U+00B7)를 `draw_text_px`가 직접 점으로 그린다.
`—` 같은 다른 기호는 쓰지 않는다. 새 폰트 에셋은 없다.

## 크기

`bpm-gui.exe` 릴리스: 4,670,464 → 4,753,408 바이트 (+81 KB).

## 확인

- 스냅샷 13장(빈 화면, 목록, 대화상자, 진행 카드, 끌어다 놓기)과 실제 데이터 화면.
- 격리된 작업 폴더에서 실제 창을 띄워: 탭 전환, 곡 추가 → 파일 선택 창 → `.bmsp` 설치 → 목록 반영,
  삭제 확인 → 삭제, 목록 새로고침 실패 시 오류 표시까지 확인.

## 남은 일

- 고DPI에서 글자가 작다(물리 px 기준). 배율 적용은 별도 작업.
- 한글 IME 입력(검색창)은 아직 없다. 붙여넣기는 된다.

## 추가 결정 (2026-10-10): 바로 설치 탭 용어

- 탭 이름은 `바로 설치`. 난이도표가 채보를 받는 곳이므로, 한 번에 설치되는 곡과 구분한다.
- 용어 규칙: **곡**은 플레이하는 것, **채보**는 난이도표 안에서만 쓴다, **곡 목록 서버**는 온라인 저장소를 가리킨다. `패키지`는 고급 도구에서만 쓴다.
- 동기화 실패 문구는 인터넷 연결을 탓하지 않는다. 자세한 오류는 콘솔에만 남긴다.
- 기본 곡 목록 서버(`packages.beetle-engine.org`)가 아직 열리지 않아 목록이 비어 있다. 탭을 숨길지는 서버가 열린 뒤 다시 정한다.
