# 신경망 편곡 실험 (2026-11-21)

`chart-arrange`의 규칙 편곡(B29) 옆에, 사람이 만든 4K·6K·8K 채보로 학습한 작은 신경망을 놓아 보는 실험입니다. 지금은 모두 `scratch/nn/`(커밋 안 됨)의 Python과 numpy로 하고, 앱에는 아직 들어가지 않았습니다.

## 1. 데이터 (`scratch/nn/extract.py`)

| 키 | 출처 | 채보 |
|---|---|---|
| 4K | UE 4K 팩(BMS), DJMAX 4B(ez2pattern 페이지) | 1,231 |
| 6K | UE 6K 팩, DJMAX 6B | 1,710 |
| 8K | UE 8K 팩(= `packages/`의 `#8K` 채보), DJMAX 8B | 415 |
| 보조 | 일반 7K·5K BMS | 737 |

- 레인 순서는 앱의 `PlayMode::restricted_lanes`(8K는 스크래치가 맨 왼쪽)를 따릅니다. DJMAX 8B는 양쪽 트리거를 바깥 레인으로 넣었습니다.
- 레벨: `tables/{4,6,8}ue-difficulty-table.tbl`의 항목을 BMS 파일 MD5로 붙였습니다(표 항목의 99.9%가 데이터에 있음). 19+는 19.5, Ω는 31로 두고, ?!와 -_-는 뺍니다.
- 곡 단위로 train/val/test를 나눕니다. UE 8K가 있는 곡(72곡)은 test 20%·val 10%, 나머지 곡은 5%·5%입니다.

## 2. 평가 (`scratch/nn/eval.py`)

사람 채보의 레인을 지우고 같은 키 수로 다시 편곡한 뒤 원래 채보와 비교합니다. 규칙 편곡은 작은 Rust 실행 파일(`scratch/nn/evalbin`)이 `chart-arrange`를 그대로 불러서 돌립니다.

- 레인 일치: 리듬만 보고는 규칙이든 신경망이든 무작위보다 1~5%p 높은 정도라 변별력이 약합니다.
- **스타일**: 계단·트릴·연타·한 손 연속 같은 패턴 지표(`scratch/charts/tools/patstats.py`)가 사람과 얼마나 다른지를, 사람 채보들 사이의 퍼짐 단위로 잽니다.
- **레벨 변화**: 아래 3절의 추정기로 편곡 전후 레벨을 잽니다.

## 3. 레벨 추정기 (`scratch/nn/difficulty.py`)

채보 하나를 넣으면 레벨을 내놓습니다. 입력은 패턴 지표와 밀도 분위수 약 70개이고, 작은 MLP 5개를 앙상블했습니다. 곡 단위 교차검증 MAE는 0.68~0.77레벨, 순위 상관은 0.98~0.99입니다. 레벨을 가장 크게 좌우하는 것은 초당 묶음 수, 2초 구간 밀도의 상위 분위, 125ms 이내 연타입니다.

## 4. 레인 점수기 (`scratch/nn/nnfeat.py`, `train.py`)

노트를 시간 순으로 하나씩 놓습니다. 각 후보 레인마다 특징값 36개(그 레인의 마지막 타격 뒤 지난 시간, 직전 묶음과의 거리, 1·2·4·8박 전의 같은 레인, 박 위치, 손 부담, 동시치기 안의 순서 등)를 만들고, 모든 레인이 같은 MLP(36→64→64→1, 약 7천 파라미터)로 점수를 매긴 뒤 softmax로 고릅니다. 4K·6K·8K를 한 모델로 학습합니다.

test 결과(UE 채보, 스타일 / 레벨 변화):

| | 4K | 6K | 8K |
|---|---|---|---|
| 규칙 `auto` | 0.52 / +0.42 | 0.64 / +0.15 | 1.15 / +0.09 |
| 신경망, 가장 높은 점수 | 0.76 / −0.16 | 0.87 / −0.98 | 1.45 / +0.25 |
| **신경망, 온도 1 샘플링** | **0.48** / +0.16 | **0.50** / +0.20 | **0.61** / +0.30 |

- 가장 높은 점수만 고르면 같은 모양이 반복되고, 8K에서는 같은 레인 연타로 무너집니다. 시드를 고정한 샘플링이 맞습니다. 시드가 같으면 결과가 결정적이라 기록의 열쇠로 쓸 수 있습니다.
- UE 8K에서는 규칙 편곡이 무작위(1.00)보다 사람과 더 멉니다. 규칙이 DJMAX 8B에 맞춰져 있기 때문으로 보입니다.

## 5. 남은 것

- **레벨 조건 편곡 (미룸, B33)**: 레인 점수기에 목표 레벨을 입력으로 넣어, 같은 곡도 쉽게·어렵게 편곡할 수 있게 합니다. 결과가 목표 레벨에 맞는지는 3절의 추정기로 잽니다. 학습에는 1절의 표 레벨을 씁니다(DJMAX는 자체 레벨 `dj_level`이 따로 있어 척도가 다름).
- 키음과 원본 레인(GFDM에서 편곡할 때의 입력)을 특징값에 넣기, 빔 탐색과 섞기
- 앱에 넣기: int8 가중치와 정수 추론(결정론), 시드 고정 샘플링, 편곡 키에 모델 버전(`nn1`) 넣기
- DJMAX 8B의 레벨은 UE 표 척도로 잴 수 없음(추정기가 UE 8K만으로 학습됨)
